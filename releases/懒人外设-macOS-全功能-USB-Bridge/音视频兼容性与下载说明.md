# 懒人外设：音视频兼容性与下载说明

当前版本提供 **USB 音视频试用链路**。蓝牙 HID 只支持触摸板、键盘和手柄，不传送音视频。USB 音视频需要手机应用与新版 `media-bridge.py` 同时运行；旧版 `usb-bridge.py` 只处理输入事件。

## 下载

- [Android APK（GitHub 下载）](https://raw.githubusercontent.com/zhipengyue/LazyPeri/main/releases/懒人外设-Android-v0.9.9.apk)
- [Windows 全功能 USB 工具包（GitHub 下载）](https://raw.githubusercontent.com/zhipengyue/LazyPeri/main/releases/懒人外设-Windows-全功能-USB-Bridge.zip)：含 `.bat` 启动文件、输入 Bridge、音视频 Bridge 和指南。
- [macOS 全功能 USB 工具包（GitHub 下载）](https://raw.githubusercontent.com/zhipengyue/LazyPeri/main/releases/懒人外设-macOS-全功能-USB-Bridge.zip)：含 `.command` 启动文件、输入 Bridge、音视频 Bridge 和指南。
- [Windows 音视频设置指南](Windows-音视频-USB设置指南.md) / [macOS 音视频设置指南](macOS-音视频-USB设置指南.md)

电脑也可以打开 [GitHub 仓库的 releases 目录](https://github.com/zhipengyue/LazyPeri/tree/main/releases)，按系统选择 ZIP。下载后先解压，再运行里面的启动脚本。

虚拟设备由原作者提供，请从其官网安装：[Windows VB-CABLE](https://vb-audio.com/Cable/)、[Mac BlackHole](https://existential.audio/blackhole/)、[Windows/Mac OBS Studio](https://obsproject.com/download)。项目 ZIP 不包含这些第三方驱动。

## 现象与提示

| 现象 | 应检查的内容 |
| --- | --- |
| 蓝牙已连，电脑看不到手机音视频设备 | 蓝牙 HID 不承载音视频。使用项目音视频试用版请改用 USB。 |
| USB 触摸板已连接，音视频仍未连接 | 输入 Bridge 与音视频 Bridge 是两个进程。请运行 `start-media-windows.bat` 或 `start-media-mac.command`，选择模式并保持窗口打开。 |
| 脚本提示找不到 `adb` 或设备未授权 | 安装 Android Platform Tools；手机开启 USB 调试并允许此电脑。 |
| 首次安装 Python 依赖失败 | 启动脚本需要联网下载 Python 包。保留窗口错误信息并检查 Python 3 与网络。 |
| 麦克风图案不发蓝光 | 检查手机麦克风权限、系统麦克风开关及其他应用占用。 |
| 麦克风桥已连，会议软件仍无声 | 桥接程序选择虚拟音频线的**播放端**；会议软件选择其**录音端**作为麦克风。检查 48 kHz 格式。 |
| 音箱桥已连，手机无声 | 电脑系统输出设为虚拟音频线播放端；桥接程序选择其录音端；调高手机媒体音量。 |
| 摄像头桥提示找不到虚拟摄像头 | 安装 OBS。Mac 首次安装后在 OBS 中启动虚拟摄像头再停止，然后退出 OBS。 |
| 电脑摄像头列表没有手机型号 | 项目输出名为 **OBS Virtual Camera**，请在电脑应用中选择此设备。 |
| 手机预览黑屏 | 检查摄像头权限、其他应用占用或该设备是否有前置镜头。 |
| 手机 USB 设置有“网络摄像头” | 可直接选系统模式，不需要项目音视频 Bridge；应用预览与系统模式相互独立。 |
| 手机 USB 设置没有“网络摄像头” | 机型或系统未启用 UVC，可尝试本项目 USB Bridge + OBS 虚拟摄像头方案。 |

音视频桥接仅在对应手机页面前台运行；切换页面或息屏会停止麦克风采集和摄像头预览。**Windows/Mac 端尚未完成真机端到端测试**，延迟、画面方向与虚拟驱动兼容性需在目标设备验证。

参考：[Android USB 网络摄像头](https://source.android.com/docs/core/camera/webcam)、[VB-CABLE](https://vb-audio.com/Cable/)、[BlackHole](https://existential.audio/blackhole/)、[pyvirtualcam 的 OBS 设置说明](https://github.com/letmaik/pyvirtualcam)。
