懒人外设 · macOS USB 工具包

1. 将 ZIP 解压到 Mac 本地文件夹，不要在压缩包预览窗口中直接运行。
2. 电脑安装 Python 3 与 Android Platform Tools（adb）；详情见同包的 macOS-USB-授权指南.md。
3. 手机开启 USB 调试，用可传数据的线连接 Mac 并解锁；下拉通知栏，点“正在通过 USB 充电”或“USB 用途”，选择“文件传输／传输数据（MTP）”，再允许此 Mac 进行 USB 调试。
4. Mac 系统设置 → 隐私与安全性 → 无障碍，允许“终端”控制电脑；完全退出并重开终端。
5. 手机打开“懒人外设”，Mac 双击 start-usb-mac.command，保持终端窗口开启。
6. 看到“触摸板已连接”后可使用触摸板、键盘、手柄和文字输入。

此工具包不包含音视频设备桥接，不能把手机作为 Mac 麦克风、音箱或摄像头。
部分 Android 手机可在系统 USB 设置中选择“网络摄像头”，由系统直接提供摄像头功能。
